# Nairobi Securities Exchange (NSE) Equities Analysis

Exploratory data analysis, return distribution modeling, and volatility dynamics across equities listed on the Nairobi Securities Exchange (NSE).

## Overview
This project investigates historical equity price data from the Nairobi Securities Exchange, examining asset returns, correlation structures, and risk characteristics for emerging market equities.

## Key Analysis Modules
* **Return Distribution & Normality:** Analysis of daily and weekly logarithmic returns, skewness, kurtosis, and fat-tail behavior.
* **Volatility Modeling:** Rolling standard deviations, high-low volatility measures, and regime shifts across key market sectors (banking, telecom, manufacturing).
* **Correlation & Covariance:** Cross-asset correlation heatmaps to assess diversification potential in domestic equity portfolios.
